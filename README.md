# Книга контактів

Застосунок для збереження, пошуку й видалення контактів. Стан керується через
Redux Toolkit, а список контактів автоматично зберігається в localStorage за
допомогою Redux Persist. Значення фільтра не зберігається.

## Локальний запуск

```bash
npm install
npm start
```

## Перевірка та збірка

```bash
npm test -- --watchAll=false
npm run lint:js
npm run build
```
